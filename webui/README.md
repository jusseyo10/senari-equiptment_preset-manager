# 장비 판매 프리셋 로컬 편집기

`run.cmd`를 실행하면 `http://127.0.0.1:8765/`가 열립니다. Python 3만 필요하며 인터넷 연결은 사용하지 않습니다. 실행 창을 닫으면 편집기도 종료됩니다.

무기 또는 방어구와 세트를 선택하면 주옵션이 위, 부옵션이 왼쪽인 표가 나타납니다. 교차 셀은 초록색(사용)과 빨간색(미사용)으로 전환됩니다. 옵션 이름을 누르면 해당 행 또는 열 전체가 전환됩니다. 일부만 초록색인 행·열을 누르면 모두 초록색이 됩니다. 되돌리기는 최근 작업부터 최대 50번까지 지원합니다.


화면은 왼쪽 옵션 표, 가운데 프리셋 이름 목록, 오른쪽 선택 프리셋 상세의 세 영역으로 나뉩니다. 표를 수정하면 프리셋 목록이 다시 계산됩니다. 상세는 읽기 전용이며 인게임처럼 `부위 → 세트 → 메인 옵션 → 서브 옵션`을 표시합니다. 세트는 고정된 게임 순서의 3×3, 서브 옵션은 한 열로 배열합니다. 그룹 전체가 선택되면 개별 항목 대신 `모두`만 체크됩니다. 세 영역 사이 구분선을 끌어 너비를 조절할 수 있습니다.

현재 설정은 `presets.json` 파일 하나에 자동 저장됩니다. 이 파일만 백업하면 됩니다. 기존 SQLite 파일은 이전 데이터 보관용이며 실행 중에는 사용하지 않습니다.
