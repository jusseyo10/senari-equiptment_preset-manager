# 세븐나이츠 리버스 장비 판매 프리셋 편집기

무기·방어구 옵션 매트릭스를 관리하고, 판매 프리셋을 계산·검토하는 Windows용 로컬 도구입니다. 웹 화면은 내 컴퓨터에서만 열리며, 외부 서버나 인터넷 계정에 설정을 전송하지 않습니다.

## 실행

1. 저장소를 내려받거나 복제합니다.
2. Python 3을 설치합니다.
3. `시작.cmd`를 실행합니다.
4. 브라우저에서 `http://127.0.0.1:8765/`가 열립니다.

Python 표준 라이브러리만 사용하므로 별도 패키지 설치가 필요하지 않습니다. 앱을 끄려면 실행된 명령 창을 닫으세요.

## 설정 데이터

- 첫 실행 시 `webui/static/seed.json`을 바탕으로 `webui/presets.json`을 만듭니다.
- 이후 변경 내용은 해당 PC의 `webui/presets.json`에 저장됩니다.
- `presets.json`은 개인 설정 파일이라 저장소에서 제외됩니다. 다른 PC로 설정을 옮기려면 이 파일을 직접 복사하세요.
- 로컬 실행은 오프라인으로 동작하지만, 저장소를 내려받거나 업데이트할 때는 인터넷이 필요합니다.

## 개발

실행 서버는 `webui/server.py`, 화면 코드는 `webui/static/`에 있습니다. `webui/presets.json`, SQLite 보관 파일, 조사 자료와 배포용 복사본은 Git에서 제외됩니다. 배포 ZIP은 소스 폴더를 기준으로 별도 생성합니다.

이 프로젝트는 세븐나이츠 리버스 팬 제작 도구이며, 게임의 공식 제품이 아닙니다.
